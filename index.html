טיפול בטעויות של קלוד קוד

תיקון בצ'אט לא מספיק. קלוד מסכים באותו רגע, וטעות מאותו סוג חוזרת. זו הערכה שבניתי כדי שכל תיקון יהפוך לבדיקה. היא עובדת בתוך הפרויקט, בלי שרת ובלי חיבורים.

איך זה עובד

  1. hook של UserPromptSubmit מזהה בהודעה שלכם תיקון, כמו "טעית" או "כבר אמרתי". הוא רושם את ההודעה, ומזריק לקלוד הנחיה לרשום את הטעות לפני שהוא עונה.
  2. כל טעות נכנסת ל-MISTAKES.md עם ציטוט, הכלל שנשבר, מוסר השכל ומה שונה בפועל. אם לא שונה כלום, כותבים "טרם יושם". hook של Stop בודק את זה: אם נרשם תיקון ו-MISTAKES.md לא השתנה, הוא עוצר את סיום התשובה פעם אחת ומבקש רשומה. הוספנו אותו אחרי שבסשן אמיתי קלוד תיקן את הטעות ולא כתב רשומה.
  3. פעם בשבוע מודל של חברה אחרת עובר על היומן. הוא מחפש סיבת שורש ומה חוזר, ומציע כלל.
  4. כלל שאישרתם נכנס ל-LESSONS_ACTIVE.md. hook של SessionStart טוען אותו בתחילת כל סשן.
  5. פעם בחודש בודקים אם הטעות חזרה אחרי שהכלל נוסף. אם חזרה, הכלל לא עובד, ומחליפים אותו בבדיקה מכנית.

הבקרות: איך יודעים שזה עובד

בלי הבקרות האלה אין לכם דרך לדעת אם המערכת עובדת, או שהיא רק נראית מותקנת.

1. ה-hook רץ

אחרי ההתקנה, בטרמינל בתיקיית הפרויקט:

( K=$(mktemp) || { echo "לא הצלחתי ליצור קובץ זמני. לא הרצתי כלום."; exit 1; }; curl -fsSL https://raw.githubusercontent.com/guycoful/claude-mistakes-kit/main/kit/.claude/hooks/capture_correction.py -o "$K" && [ -s "$K" ] || { echo "ההורדה של ה-hook נכשלה. לא הרצתי כלום."; exit 1; }; H=""; for f in .claude/hooks/capture_correction.py .claude/hooks/mistakes_kit_capture*.py; do [ -f "$f" ] && cmp -s "$f" "$K" && H="$f" && break; done; [ -n "$H" ] || { echo "לא נמצא hook זהה לקובץ של הערכה. לא הרצתי כלום."; exit 1; }; T=$(mktemp -d) && [ -d "$T" ] || { echo "לא הצלחתי ליצור תיקייה זמנית. לא הרצתי כלום."; exit 1; }; echo "$H"; echo '{"prompt":"טעית, כבר אמרתי לך"}' | CLAUDE_PROJECT_DIR="$T" python3 "$H" )

בשורה הראשונה מופיע שם ה-hook של הערכה שהותקן. אחריה צריכה להופיע ההנחיה שמתחילה ב-[טיפול בטעויות]. הבדיקה רצה בתיקייה זמנית, ולכן היא לא מוסיפה שורה ל-candidates.jsonl שלכם. הבקרה מריצה רק קובץ שזהה בדיוק ל-hook שבריפו. אם מופיע "לא נמצא hook זהה", ה-hook לא הותקן, או שהערכה עודכנה מאז ההתקנה ואז מתקינים שוב.

2. קלוד קוד רואה את ה-hooks

בסשן חדש של קלוד קוד:

/hooks

צריכים להופיע UserPromptSubmit ו-SessionStart. אם לא, ה-settings.json לא נטען, או שהסשן נפתח לפני ההתקנה.

3. תיקון אמיתי נרשם

בסשן, אחרי טעות אמיתית, תכתבו תיקון עם אחד הביטויים. אחר כך:

git diff .claude/lessons/MISTAKES.md

צריכה להיות רשומה חדשה, עם ציטוט, מוסר השכל ופתרון. אם יש שורה ב-candidates.jsonl ואין רשומה, קלוד קיבל את ההנחיה ולא ביצע. אז תכתבו לו את זה, וזו עוד רשומה.

4. הלקחים נטענים

אחרי שיש לפחות כלל אחד ב-LESSONS_ACTIVE.md, בסשן חדש תשאלו:

מה הלקחים הפעילים שקיבלת בתחילת הסשן ?

הוא צריך לצטט אותם מילה במילה. אם הוא מסכם או ממציא, ה-SessionStart לא עבד.

5. ה-hook לא מפספס

פעם בשבוע, תספרו:

python3 -c "import json,os,datetime as D;f='.claude/lessons/candidates.jsonl';t=D.date.today();s=(t-D.timedelta(6)).isoformat();e=t.isoformat();R=[json.loads(l) for l in open(f,encoding='utf-8') if l.strip()] if os.path.exists(f) else [];W=[r for r in R if s<=r['ts'][:10]<=e];print(len(W),'מועמדים',s,'עד',e);[print(r['ts'][:16],r.get('context') or r['text'][:200]) for r in W]"

מודפסות השורות מ-7 הימים האחרונים, כולל היום, עם הקטע שסביב ביטוי התיקון. אם עוד אין קובץ, יופיע 0. תעברו על התיקונים שכתבתם השבוע, אחד אחד, ותבדקו שלכל אחד יש שורה. תיקון שלא נתפס אומר שחסר ביטוי ב-MARKERS בתוך ה-hook. תוסיפו את המילים שאתם באמת כותבים.

6. הכלל באמת עובד

פעם בחודש, הפרומפט החודשי למטה.

כלל שאחריו הטעות חזרה לא עובד. אותו מחליפים בבדיקה מכנית, hook או סקריפט, ולא בכלל ארוך יותר.

הבודק השבועי

פותחים צ'אט חדש ב-ChatGPT או ב-Gemini, מצרפים את MISTAKES.md ומדביקים:

אתה בודק. לא כתבת את הרשומות האלה, ואין לך את ההסברים של מי שכתב אותן.
לכל רשומה מהשבוע האחרון:
1. סיבת השורש במשפט אחד, עם ציטוט מהרשומה.
2. האם היא חוזרת על רשומה קודמת, ועל איזו.
3. האם "הפתרון שיושם" באמת מונע את הטעות, או רק מבטיח להיזהר.
4. בדיקה אחת שאפשר להוסיף: hook, סקריפט, או בדיקה של קורא לפני שהתוצר יוצא.
בסוף: הדפוסים שחזרו לפחות 3 פעמים, ולכל אחד כלל קצר ל-LESSONS_ACTIVE.md.
אל תבנה דפוס משורה אחת.

הבדיקה החודשית

גם היא בצ'אט של מודל אחר, עם שני הקבצים:

מצורפים MISTAKES.md ו-LESSONS_ACTIVE.md.
לכל כלל ב-LESSONS_ACTIVE.md:
1. מתי הוא נוסף.
2. האם אחרי התאריך הזה יש ב-MISTAKES.md רשומה מאותו סוג. אם יש, תצטט אותה.
3. אם הטעות חזרה: איזו בדיקה מכנית (hook או סקריפט) הייתה תופסת אותה, במקום כלל כתוב.
אל תניח שכלל עובד רק מפני שהוא כתוב.

הקבצים, להתקנה ידנית

אותם קבצים שהפרומפט מוריד. אפשר גם בריפו.

.claude/hooks/capture_correction.py
#!/usr/bin/env python3
# UserPromptSubmit hook: מזהה תיקון בהודעה שלך, רושם אותו, ומזריק לקלוד את הלקחים הפעילים לפני שהוא עונה.
# עם --stop הוא רץ כ-Stop hook: אם נרשם תיקון ו-MISTAKES.md לא השתנה, הוא עוצר את סיום התשובה פעם אחת ומבקש רשומה.
import sys, json, re, os, datetime, hashlib


def lessons_dir(data):
    return os.path.join(os.environ.get("CLAUDE_PROJECT_DIR") or data.get("cwd") or os.getcwd(), ".claude", "lessons")


def mistakes_sig(base):
    try:
        return hashlib.sha256(open(os.path.join(base, "MISTAKES.md"), "rb").read()).hexdigest()
    except OSError:
        return ""

try:
    data = json.load(sys.stdin)
except Exception:
    sys.exit(0)

if "--stop" in sys.argv[1:]:
    base = lessons_dir(data)
    pending = os.path.join(base, ".pending_entry.json")
    if not os.path.exists(pending):
        sys.exit(0)
    try:
        before = json.load(open(pending, encoding="utf8")).get("mistakes_sig", "")
    except Exception:
        before = ""
    if mistakes_sig(base) != before or data.get("stop_hook_active"):
        os.remove(pending)
        sys.exit(0)
    print(json.dumps({"decision": "block", "reason":
        "[טיפול בטעויות] בהודעה האחרונה נרשם תיקון, ו-.claude/lessons/MISTAKES.md לא השתנה. "
        "לפני שאתה מסיים, תוסיף שם רשומה לפי הפורמט שבקובץ, עם מוסר השכל ומה שונה בפועל. "
        "אם לדעתך לא טעית, תוסיף רשומה שמסבירה למה, עם ציטוט."}, ensure_ascii=False))
    sys.exit(0)

text = (data.get("prompt") or "")[:1500]
if not text:
    sys.exit(0)

# ביטויים שאתה משתמש בהם כשאתה מתקן. כדאי להתאים לשפה שלך.
MARKERS = [r"טעית", r"לא נכון", r"אתה אמור", r"כבר אמרתי", r"ביקשתי", r"לא בדקת", r"שוב ",
           r"\bwrong\b", r"you should have", r"I already told you"]
found = [(m, re.search(m, text, flags=re.I)) for m in MARKERS]
found = [(m, x) for m, x in found if x]
if not found:
    sys.exit(0)
hits = [m for m, x in found]
# שומרים את תחילת ההודעה וגם קטע סביב הביטוי הראשון, כדי שתיקון בסוף הודעה ארוכה לא יאבד
pos = min(x.start() for m, x in found)
context = text[max(0, pos - 200):pos + 200]

base = lessons_dir(data)
os.makedirs(base, exist_ok=True)
with open(os.path.join(base, ".pending_entry.json"), "w", encoding="utf8") as f:
    json.dump({"ts": datetime.datetime.now().isoformat(timespec="seconds"), "mistakes_sig": mistakes_sig(base)}, f)
with open(os.path.join(base, "candidates.jsonl"), "a", encoding="utf8") as f:
    f.write(json.dumps({"ts": datetime.datetime.now().isoformat(timespec="seconds"),
                        "markers": hits, "text": text[:300], "context": context}, ensure_ascii=False) + "\n")

print("[טיפול בטעויות] בהודעה הזו יש תיקון. לפני שאתה עונה:")
print("1. תכתוב איזה כלל נשבר.")
print("2. תבדוק ב-.claude/lessons/MISTAKES.md אם טעות כזו כבר הופיעה.")
print("3. תוסיף רשומה לפי הפורמט שבקובץ, עם מוסר השכל ומה שונה בפועל.")
print("4. אם לדעתך לא טעית, תכתוב למה, עם ציטוט. אל תסכים רק כדי לרצות.")
rules = os.path.join(base, "LESSONS_ACTIVE.md")
if os.path.exists(rules):
    print(open(rules, encoding="utf8").read())

# יומן טעויות

## פורמט
תאריך | מה קרה, עם ציטוט | הכלל שנשבר | מה בודקים בפעם הבאה | חוזרת ? (כן, עם תאריך קודם, או לא)
מוסר השכל: המשפט הכללי, כך שיחול גם על מקרים אחרים.
הפתרון שיושם: מה שונה בפועל (כלל ב-LESSONS_ACTIVE.md, hook או סקריפט), עם נתיב. אם לא שונה כלום: "טרם יושם", ומה מוצע.

## רשומות
CLAUDE-section.md
## טעויות
- כשאני מתקן אותך, תוסיף רשומה ל-.claude/lessons/MISTAKES.md לפי הפורמט, באותו רגע ולא בסוף הסשן.
- רשומה בלי "מוסר השכל" ובלי "הפתרון שיושם" לא גמורה.
- לפני שאתה כותב רשומה, תחפש ב-MISTAKES.md טעות דומה. אם יש, תסמן "חוזרת" עם התאריך הקודם.
- טעות שחוזרת פעם שנייה: תציע כלל קצר ל-LESSONS_ACTIVE.md, ותחכה לאישור שלי לפני שאתה מוסיף אותו.
- אל תסכים איתי רק כדי לרצות. אם לדעתך לא טעית, תכתוב למה, עם ציטוט.

מה הערכה לא עושה

ה-hook מזהה רק את הביטויים שברשימה, ובודק רק את 1,500 התווים הראשונים של ההודעה. תיקון בסוף הודעה ארוכה לא נתפס. תיקון שכתוב אחרת לא נתפס, ולכן קיימת בקרה 5. כלל כתוב לא מבטיח כלום, ולכן קיימת בקרה 6. וגם היומן לא כותב את עצמו. אם קלוד מקבל את ההנחיה ולא רושם, בקרה 3 תראה את זה.
